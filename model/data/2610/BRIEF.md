# Глубокий анализ цен и маржи — бриф для агентов

Клиент: поставщик в госзакупки/коммерческие закупки РФ, **УСН 15% (доходы минус расходы)**, НДС не платит.
Цена заявки = цена контракта («НДС не облагается»). Закупочные цены поставщиков берём С НДС (входной НДС — в расходы).
Сегодня 26.10.2026. Подача готовится сейчас — лоты с подачей 27.10 считать только если успеваем.

## Модель прибыли (использовать ровно её)
P = НМЦК × (1 − d)            # d — снижение на торгах
pre = P − C − L − P×0.008 − (C+L)×0.20×60/365     # C — закупка, L — логистика, 0.8% прочие (ЭП, банк), 20% годовых стоимость денег на 60 дней
net = pre − 0.15×max(pre,0)
Безубыточное снижение d* — где net=0 (бисекция).
Ожидаемое снижение d: 44-ФЗ аукцион 10–25% (по категории), запрос котировок 5–15%, 223/коммерция 5–15%.
Одежда: правило клиента — себестоимость форменных комплектов: **летний комплект 3 500 ₽, зимний комплект 5 000 ₽** (их собственное производство/поставщик). Для прочих позиций одежды/обуви/СИЗ — искать реальные рыночные оптовые цены российских производителей/оптовиков (Восток-Сервис, Техноавиа, Энергоконтракт, Авангард-Спецодежда, Трак, Спецобъединение, ФАРАДЕЙ, Ursus, Торнадо, Lebron и т.п.) — с URL.

## Где брать позиции и цены НМЦК
- 44-ФЗ: `curl -s https://v2test.gosplan.info/fz44/purchases/{номер}/notification` → source.notificationInfo.purchaseObjectsInfo.notDrugPurchaseObjectsInfo.purchaseObject[] (name, quantity.value, OKEI, price). Лимит частоты: при «rate limit» ждать 25 с (используй python time.sleep в цикле, НЕ bash sleep).
- 223-ФЗ: `https://v2test.gosplan.info/fz223/purchases/{номер}` → lotItem[] (qty, okei, additionalInfo). Цен за ед. обычно нет — делить НМЦК пропорционально рыночным ценам.
- zakupki.gov.ru часто 503 — пробуй, но не застревай. Агрегаторы: bicotender.ru, rostender.info, saby.ru/tenders, tenderguru, b2b-center (часто закрыто).
- Коммерческие без НМЦК: спецификации часто закрыты логином площадки. Тогда: определи по названию типовые позиции, найди **рыночные цены продажи** (что реально ставят конкуренты / розница-опт) и **закупочные** (дилер/завод), дай рекомендуемую цену КП и ожидаемую маржу, confidence=low.

## Правила
- Ничего не выдумывать. Каждая цена — с URL источника или пометкой [оценка] + обоснование.
- Нацрежим ПП 1875: одежда/обувь/ткани — запрет иностранного; ЗРА/кабель — ограничения; учитывай (нужен российский товар).
- Если позиции неизвестны и найти нельзя — так и написать, оценить по аналогам, confidence=low.
- Дубли (одна закупка на разных площадках) — пометить.

## Формат результата
Запиши JSON-массив в файл, указанный в задании. Элемент на лот:
```
{"num":"", "name":"", "cust":"", "law":"", "method":"", "end":"", "nmck":число|null,
 "positions":[{"item":"","qty":число|null,"unit":"","nmck_unit":число|null,"cost_unit":число|null,"cost_src":"url или [оценка]: почему"}],
 "cost_total":число|null, "logistics":число|null,
 "margin_pct":число|null,            # (НМЦК−C−L)/НМЦК
 "net_at_nmck":число|null, "exp_disc":число|null, "net_expected":число|null, "breakeven_disc":число|null,
 "kp_price":число|null,              # для лотов без НМЦК — рекомендуемая цена КП (сумма), иначе null
 "kp_margin_pct":число|null,
 "decision":"Участвовать|Осторожно|Нет|Запросить спецификацию",
 "risks":"кратко", "confidence":"high|med|low", "sources":["url",...]}
```
Финальный ответ агента — короткая сводка (5–10 строк): сколько лотов, сколько «Участвовать», суммарная net_expected, главные находки.
