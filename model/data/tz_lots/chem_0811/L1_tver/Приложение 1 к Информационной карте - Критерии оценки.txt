Порядок оценки Заявок Участников
Оценка Заявок Участников осуществляется Комиссией по закупкам                      ООО «Тверь Водоканал», которая руководствуется в свое деятельности законодательством Российской Федерации и Положением о закупке товаров, работ, услуг ООО «Тверь Водоканал». Подлежат оценке только допущенные заявки Участников.
При оценке и ранжировании по степени предпочтительности Заявок на участие в конкурентных закупках на оказание услуг, выполнение работ применяются стоимостной и нестоимостной критерий.
Основные понятия:
«оценка» - процесс выявления в соответствии с условиями определения поставщиков (подрядчиков, исполнителей) по критериям оценки и в порядке, установленном в документации о закупке, лучших условий исполнения договора, указанных в заявках (предложениях) участников закупки, которые не были отклонены;
«значимость критерия оценки» - вес критерия оценки в совокупности критериев оценки, установленных в документации о закупке, выраженный в процентах;
«коэффициент значимости критерия оценки» - вес критерия оценки в совокупности критериев оценки, установленных в документации о закупке, деленный на 100;
«рейтинг заявки (предложения) по критерию оценки» - оценка в баллах, получаемая участником закупки по результатам оценки по критерию оценки с учетом коэффициента значимости критерия оценки.
№ п/п | Критерий оценки заявок | Значимость  критерия оценки
1 | Стоимостной критерий  (цена Договора, предложенная Участником) | 90%
2 | Нестоимостные критерии (срок поставки партии товара) | 10%
Всего | 100%
Рейтинг представляет собой оценки в баллах, получаемые по результатам оценки по критериям. Дробное значение рейтинга округляется по двух десятичных знаков после запятой по математическим правилам округления.
При этом для расчетов рейтингов применяется коэффициент значимости, равной значению соответствующего критерия в процентах, деленному на 100. Сумма значимостей критериев оценки заявок составляет 100%.
Оценка стоимостного критерия:
Стоимостные критерии оценки: цена договора, с учетом всех затрат, издержек и иных расходов Исполнителя, за исключением НДС, связанных с исполнением настоящего договора, значимость критерия 90% (коэффициент значимости критерия 0,90). При оценке заявок по данному критерию оценки лучшим условием исполнения договора признается предложение участника закупки с наименьшей ценой договора. В случае если в заявке участника закупки указана цена договора превышающая начальную (максимальную) цену, заявка такого участника отклоняется как несоответствующая требованиям документации, другие показатели заявки не рассматриваются.

2.1 Порядок оценки критерия «Срок поставки партии товара (календарный день)»
Оценка заявок по данному критерию производится по показателям, которые приведены в таблице, значимость критерия 10% (коэффициент значимости критерия 0,10):
Предмет оценки | Принцип расчета критерия
Срок поставки партии товара с момента направления Заказчиком в адрес Поставщика отгрузочной разнарядки, в календарных днях предложенный Участником, но не более срока указанного в Техническом задании (Приложение № 1 Документации) Сведения подтверждаются Формой               № 2 «Технико-коммерческое предложение» (Раздел № 3 документации), где участник указывает срок поставки партии товара с момента направления Заказчиком в адрес Поставщика отгрузочной разнарядки, в календарных днях. | СВРi = КЗ x 100 x (Сmin / Сi), где: СВРi - оценка i-й заявки участника  КЗ - коэффициент значимости критерия (0,10). Сmin – минимальный срок поставки среди заявок Участников Сi – срок поставки в заявке i-го Участника
Рейтинг заявки по критерию «Срок поставки партии товара (календарный день)» равен оценке в баллах, полученной участником закупки по результатам оценки по критерию оценки, с учетом коэффициента значимости критерия 0,10.
Показатели, по которым отсутствуют предложения, оцениваются нулевым количеством баллов. Для оценки заявки осуществляется расчет итогового рейтинга (R) по каждой заявке по формуле:
R = ЦБi + СВРi, где:
R – итоговой рейтинг заявки участника;
ЦБi – оценка заявки участника по  критерию «Цена Договора»
СВРi – оценка заявки участника по критерию «Срок поставки партии товара (календарный день)»
Победителем признается участник закупки, заявке которого присвоен самый высокий итоговый рейтинг. Заявке такого участника закупки присваивается первый порядковый номер. При равенстве баллов участников, наилучшей признается заявка участника, которая была подана ранее.
