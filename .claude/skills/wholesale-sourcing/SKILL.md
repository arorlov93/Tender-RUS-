# Оптовый поиск и проверка поставщиков (ISP Group LLC / ГИДРОПАС)

Цель: по названию товара или по присланному КП выдать (1) таблицу предложений, приведённых к одной базе, (2) проверку каждого поставщика с красными/зелёными флагами, (3) себестоимость единицы в Москве, (4) письмо поставщику. Результат — Excel + PDF (≤2 стр.) в корне репозитория, коммит и пуш.

Правила: ничего не выдумывать — у каждой цены и факта URL и дата; оценки (фрахт, брокер, агент) явно помечать «оценка». Банковские реквизиты своей компании в git не коммитить. Не советовать скрывать конечную страну назначения (Россия/Беларусь) — это обход санкций.

## Шаг 1. Разобрать запрос
- Товар: точное наименование, объём/фасовка, вкус/марка, штрихкод (EAN, напр. Red Bull 250 мл = 9002490100070), количество, страна происхождения.
- Если прислано КП (PDF/текст) — извлечь: продавец, страна, VAT/рег. номер, адрес, цена за коробку/единицу, кол-во, Incoterms (EXW/FCA/DAP/DDP), условия оплаты, срок, подписант. `pdftotext -layout file.pdf -`.
- Пересчитать цену в € за единицу (за банку = цена коробки / шт. в коробке).

## Шаг 2. Найти предложения (параллельно, агентами при объёме)
Источники и приёмы поиска — `references/sources.md`. Минимум: Parallelbroker (FMCG параллельный импорт ЕС), Europages/Kompass/wlw (дистрибьюторы ЕС), Alibaba/B2B-доски (осторожно — много мошенников), официальные дистрибьюторы бренда в стране, cash & carry (Metro/Makro/Selgros) как верхняя граница, контракты/тендеры как факт рынка.
Ориентир «здравого смысла» по цене — `references/price_benchmarks.md` (напр. выручка Red Bull ≈ €0,87 за банку: цена заметно ниже = красный флаг).

## Шаг 3. Проверить каждого поставщика
1. `python3 scripts/check_company.py <CC> <VAT/NIP>` — VIES (ЕС) + для Польши белый список МинФина (статус НДС, KRS, дата регистрации, **банковские счета**). Сравнить название и адрес с КП, счёт в инвойсе — с белым списком.
2. Национальные реестры по стране — `references/sources.md` (PT eInforma/racius, PL KRS/biznes.gov.pl, DE northdata/handelsregister, NL KVK, LT Registrų centras, CZ ARES).
3. Поиск следов: сайт и его возраст (whois), телефоны и e-mail (совпадают ли с реестром), жалобы (scamadviser, trustpilot, reddit, 419scam), предупреждения бренда.
4. Пройти чек-лист `references/red_flags.md`, выставить риск: низкий / средний / высокий.

## Шаг 4. Себестоимость в Москве
Заполнить JSON по образцу `examples/redbull_vievita.json` (товары, цены, кол-во, маршрут, ставки) и запустить:
`python3 scripts/landed_cost.py examples/<file>.json --out ../ИМЯ_ФАЙЛА` → Excel + HTML (+PDF, если есть chromium).
Модель: цена → банк/агент → фрахт до ЕАЭС → пошлина ЕАЭС → акциз РБ → сборы/брокер/декларация/импортёр РБ → стикер, «Честный знак», склад → фрахт в Москву → акциз РФ → НДС РФ (один НДС: НДС РБ возмещён при экспорте в РФ по 0 %; два НДС: НДС РБ не возмещён и входит в базу НДС РФ). Ставки по умолчанию и их источники — в `examples/redbull_vievita.json` (сверять с брокером).

## Шаг 5. Итог и письмо
- Таблица: поставщик | страна | € за ед. | Incoterms | MOQ | оплата | риск | себестоимость в Москве (1 НДС / 2 НДС) | ссылка.
- Рекомендация: с кем работать и на каких условиях оплаты. Первая сделка — только эскроу / аккредитив / Trade Assurance или оплата после проверки товара на складе (видео/SGS); платёж только на счёт продавца в его стране и на его имя (для PL — счёт из белого списка).
- Письмо поставщику — `templates/rfq_en.md` (первый запрос) или `templates/followup_en.md` (повтор/уточнения, «как мы уже писали»). Писать по-человечески, без длинных тире. Плательщик — ISP Group LLC (США), конечный получатель — импортёр в Минске.
