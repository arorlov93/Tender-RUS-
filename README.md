# Tender-RUS

Исследование рынка закупок РФ (44-ФЗ, 223-ФЗ, коммерческие закупки, открытые закупки Минобороны): 15 товарных позиций для поставок.

- [REPORT.md](REPORT.md) — итоговый отчёт (10 разделов + длинный список из 58 позиций).
- [model/econ.py](model/econ.py) — сценарная модель экономики сделки, чувствительность, оборотный капитал. Запуск: `python3 model/econ.py model/econ.json`.
- [model/score.py](model/score.py) — взвешенный рейтинг (веса из ТЗ).
