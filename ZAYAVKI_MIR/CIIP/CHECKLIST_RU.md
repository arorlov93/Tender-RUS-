## 2. Юридические риски (критично)

1. **GPA не покрывает США в секторе воды.** Bando IV.1.8: «AAP (GPA) — NO». В приложении 3 ЕС к GPA прим. 6(b): закупки организаций сектора питьевой воды **не покрыты для поставщиков из США**. По решению CJEU Kolin (C‑652/22) у ISP нет права требовать допуска; CIIP может допустить по своему усмотрению. Disciplinare §17 прямо упоминает участников «не из ЕС» (эквивалентные декларации, ст. 69) — это скорее говорит о допуске. **Действие:** задать анонимный вопрос №1 (файл Q_…) до 24.11; запасной путь — подача через компанию из ЕС (RTI с европейским дистрибьютором как mandataria).
2. **Ст. 170 D.Lgs. 36/2023 (ст. 85 Директивы 2014/25):** отклонение возможно, если >50% стоимости товаров — из стран без соглашения. Китай (Bluwat — к тому же без REACH) → не использовать. **Продукт из ЕС (Испания/Германия/Франция) → 0% → риска нет.** Само американское происхождение ISP на ст. 170 не влияет (важно происхождение товара).
3. **Испытание** при очень низких дозах из Allegato A (27–70 г эмульсии/кг SS; Brodolini 27 г/кг при 28% сухого) — провал = нет контракта. Нужен инженер-технолог производителя + предварительный jar-test.
4. **Оборот и референции** — если у ISP нет своих, без avvalimento участие невозможно.
