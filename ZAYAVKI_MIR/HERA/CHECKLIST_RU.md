## 3. Анализ доступа и ст. 170

- **GPA:** приложение 3 ЕС, прим. 6(b): закупки организаций сектора **питьевой воды не покрыты для поставщиков из США**. У ISP нет права на допуск (CJEU Kolin C‑652/22); HERA может допустить или исключить. Нужен вопрос через «Messaggi» (файл Q_…, №1) — это стратегическое решение: вопрос привлечёт внимание к статусу ISP. Альтернатива — участие через итальянского/европейского партнёра-мандатария (Opzione C в A5).
- **Ст. 170 D.Lgs. 36/2023:** важна страна происхождения угля. GAC из ЕС (CarboTech — DE, Norit — NL, Grand Activated — PL) → 0% «непокрытого» происхождения → риска нет. Китайский GAC (аудит: 1,21 €/кг) → >50% → HERA вправе отклонить и обязана предпочесть заявку из ЕС при разнице ≤3%. **Китай не рекомендуется.**
- **Работы на месте:** нужна итальянская фирма с Albo Gestori Ambientali (кат. 4/5), **White List** префектуры (перевозка/утилизация отходов для третьих лиц — «чувствительная» деятельность, L. 190/2012 ст. 1 п. 53), квалификацией для работ в замкнутых пространствах (DPR 177/2011), POS. Поэтому структура: **ISP (подаёт) + avvalimento у производителя угля (оборот+референции) + 100% субподряд работ итальянской фирме** (A5).
